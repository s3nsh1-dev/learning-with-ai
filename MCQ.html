Stage 1 Acronym Glossary

  • GHCR — GitHub Container Registry: GitHub-hosted private OCI container registry storing our client and server images.
  • SHA — Secure Hash Algorithm: The 40-character Git commit hash (e.g. 9f8a32b) used as an immutable image tag.
  • SSH — Secure Shell: Remote cryptographic network protocol used to run deployment commands on EC2 via dedicated deploy keys.
  • SSM — AWS Systems Manager: Cloud-native management service that executes remote commands through an agent, avoiding open inbound SSH ports.
  • OIDC — OpenID Connect: Token exchange protocol allowing GitHub Actions to authenticate directly with AWS IAM without static credentials.
  • TLS — Transport Layer Security: Cryptographic protocol encrypting database connections between Express and Neon (port 5432).
  • OCI — Open Container Initiative: Industry specification ensuring Docker images run reliably across compliant engines and registries.
  • E2E — End-to-End Testing: Complete system testing (using Playwright) against the full stack rather than mocked single components.
  • PAT — Personal Access Token: Scoped GitHub token used on EC2 with read-only package access.
  • CORS — Cross-Origin Resource Sharing: Browser security policy bypassed in production because Nginx serves the frontend and proxies /api on port 80.
