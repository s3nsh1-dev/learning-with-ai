Stages 5 & 6 Acronym Glossary

  • EC2 — Elastic Compute Cloud: AWS virtual server running Ubuntu Linux for hosting Docker Compose stacks.
  • SSH — Secure Shell: Cryptographic network protocol for remote command execution and configuration management.
  • SG — Security Group: AWS virtual firewall regulating inbound and outbound port traffic at the host hypervisor layer.
  • GHCR — GitHub Container Registry: GitHub's private OCI registry hosted at ghcr.io for storing and distributing versioned Docker images.
  • PAT — Personal Access Token: GitHub credential scoped strictly to read-only package access (read:packages) on the host.
  • OCI — Open Container Initiative: Open standards for container formats, runtime images, and registry specifications.
  • SHA — Commit Hash (40-char): Cryptographically unique identifier for a Git commit; used for immutable container image tags.
  • YAML — YAML Ain't Markup Language: Human-readable data serialization format used to define Docker Compose contracts.
  • DNS — Domain Name System: Docker's internal embedded resolver at 127.0.0.11 routing container service names.
  • TCP — Transmission Control Protocol: Network transport protocol over which HTTP and database sockets communicate.
  • HTTP — Hypertext Transfer Protocol: Request-response protocol validated by the public /api/health smoke check.
  • ENV — Environment Variables: Key-value configuration pairs used in release.env and server.env.
