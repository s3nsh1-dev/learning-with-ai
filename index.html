When it runs · restart

Only the last column separates the two you would actually use

Value Process crashes Daemon restarts After you run stop
no stays down stays down stays down
on-failure restarts stays down stays down
unless-stopped restarts comes back stays down
always restarts comes back comes back anyway

Stop a container under always, reboot, and it is running again — the policy outranks your decision. Use unless-stopped.

The daily loop

Five commands, and one of them deletes your rows

Command Containers Network After it, docker volume ls shows
stop stopped, kept kept myapp_pgdata
down removed removed myapp_pgdata
down -v removed removed nothing

./app is unaffected by all three. A bind mount is a path on your disk, not an object Docker owns, so no Compose command can remove it.
